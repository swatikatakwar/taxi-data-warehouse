
# Project Charter

## 1. Project Name

End-to-End Taxi Analytics Data Warehouse

## 2. Business Background

A transportation analytics company receives
large volumes of taxi trip records.

The company wants to centralize this information
to analyze trip volumes, revenue, payment patterns,
pickup locations and operational performance.

## 3. Business Problem

Raw transportation data is not organized into
a centralized analytical structure.

This makes reporting, historical comparisons
and business analysis difficult.

## 4. Project Objective

Build a scalable analytics data warehouse that
processes raw trip records and provides reliable,
structured data for business reporting.

## 5. Scope

- Data extraction using Python.
- Data cleaning and transformation.
- SQL Server staging and warehouse development.
- Star schema data modeling.
- Incremental ETL processing.
- Data quality monitoring.
- SQL performance optimization.
- Power BI dashboard development.

## 6. Expected Deliverables

- Python ETL pipeline.
- SQL Server data warehouse.
- Fact and dimension tables.
- Data quality audit framework.
- Performance optimization report.
- Power BI dashboard.
- Technical documentation.

## 7. Project Success Criteria

- Successfully process more than one million records.
- Maintain data integrity across warehouse tables.
- Support repeatable and incremental data loading.
- Generate reliable business reporting metrics.
- Document pipeline performance and validation results.
