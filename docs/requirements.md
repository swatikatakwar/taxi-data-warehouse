
# Project Requirements

## Software Requirements

| Software | Purpose |
|---|---|
| Python | ETL development |
| VS Code | Python development |
| Pandas | Data processing |
| SQL Server | Data warehouse |
| SSMS 22 | SQL development |
| Power BI Desktop | Data visualization |
| Git | Version control |
| GitHub | Project hosting |

## Functional Requirements

1. Extract data from public datasets.
2. Transform and clean source records.
3. Load data into SQL Server.
4. Maintain fact and dimension tables.
5. Support incremental data loading.
6. Record pipeline execution logs.
7. Validate data quality.
8. Generate analytical reports.

## Non-Functional Requirements

1. Data accuracy and consistency.
2. Reliable pipeline execution.
3. Maintainable code structure.
4. Efficient SQL query performance.
5. Reproducible ETL processing.
