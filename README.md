
# End-to-End Taxi Analytics Data Warehouse

## Project Overview

This project focuses on building an end-to-end analytics
data pipeline using NYC Yellow Taxi trip records.

The solution will extract, transform, validate and load
raw data into a SQL Server data warehouse using a
star schema.

Power BI will be used to create interactive dashboards
for business analysis and reporting.

## Technologies

- Python
- Pandas
- SQL Server
- T-SQL
- Power BI
- Git and GitHub

## Project Objectives

1. Build a structured data warehouse.
2. Develop an automated ETL pipeline.
3. Implement incremental data loading.
4. Create data quality validation checks.
5. Optimize SQL query performance.
6. Develop an interactive Power BI dashboard.
